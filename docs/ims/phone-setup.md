# 手机端 VoLTE/IMS 设置

在私有网络实验中，即使核心网和 IMS 侧已就绪，手机端也需要做额外设置才能启用 VoLTE。大多数手机出厂默认仅对运营商白名单 SIM 卡开放 VoLTE 开关，使用实验用 SIM 卡时需要手动解锁。

本页汇总不同品牌/机型的具体操作方法。

::: warning 注意
拨号盘暗码操作可能因 MIUI/HyperOS/Android 版本不同而有差异。若暗码无反应，请确认系统版本或尝试其他方法。
:::

## 小米 / Redmi / POCO（MIUI / HyperOS）

小米系手机默认会检查 SIM 卡所属运营商，仅在运营商白名单内才显示 VoLTE 开关。实验用 SIM 卡（如 sysmoISIM）不在白名单中，因此需要先禁用运营商检查。

### 步骤

1. **禁用 VoLTE 运营商检查**

   打开拨号盘，输入以下暗码：

   ```
   *#*#86583#*#*
   ```

   输入完成后会自动触发（无需按拨号键）。该操作**禁用**运营商白名单检查，使 VoLTE 开关在任意 SIM 卡下可见可控。

   ::: tip 提示
   此操作是一个 toggle——再次输入同一暗码会重新启用运营商检查。
   :::

2. **开启 VoLTE**

   进入 **设置 → 双卡与移动网络 → 选择对应 SIM 卡**，打开 **VoLTE 高清通话** 开关。

3. **验证**

   - 开启后状态栏信号图标旁应出现 "HD" 或 "VoLTE" 标识
   - 在 IMS 注册成功后，可通过拨打测试号码验证语音通话

## 通用排查思路

如果手机无法完成 IMS 注册或 VoLTE 通话，按以下顺序排查：

1. **SIM 卡配置是否正确**：IMSI、Ki、OPc 是否与 Open5GS 订阅者数据匹配
2. **APN 是否配置**：确保手机有 `ims` APN（部分手机需手动添加）
3. **VoLTE 开关是否可见/开启**：参考上方品牌特定步骤解锁开关
4. **P-CSCF 是否可达**：UE 需能通过 IMS PDU 会话/APN 访问 P-CSCF 地址
5. **核心网日志**：检查 Open5GS 和 Kamailio 日志确认注册信令是否到达
