# 无线电法规与合规要求

::: danger ⚠️ 重要警告
在进行任何无线电发射实验之前，请务必了解并遵守相关法律法规。**违法使用无线电设备可能导致行政拘留甚至刑事处罚！**
:::

## 为什么需要了解无线电法规？

软件定义无线电 (SDR) 和私有 5G 网络实验涉及无线电频率的使用。在中国，无线电频谱是国家资源，受到严格管理。未经许可的无线电发射可能：

- 干扰民用通信（手机信号、WiFi 等）
- 干扰航空、铁路、应急通信等关键基础设施
- 影响国家安全和公共安全
- **导致法律处罚**

## 中国无线电管理相关法规

### 《中华人民共和国无线电管理条例》

这是中国无线电管理的基本法规，主要规定：

- 无线电频谱资源属于国家所有
- 设置、使用无线电台（站）须经批准
- 无线电发射设备须取得型号核准
- 禁止干扰合法无线电业务

### 《中华人民共和国治安管理处罚法》(2026年1月1日起施行)

::: danger 🚨 2026年新规 - 请特别注意！
自2026年1月1日起施行的新版《治安管理处罚法》对无线电违法行为有明确的处罚规定：
:::

> **第三十二条** 违反国家规定，有下列行为之一的，处5日以上10日以下拘留；情节严重的，处10日以上15日以下拘留：
> 
> （一）故意干扰无线电业务正常进行的；
> 
> （二）对正常运行的无线电台（站）产生有害干扰，经有关主管部门指出后，拒不采取有效措施消除的；
> 
> （三）**未经批准设置无线电广播电台、通信基站等无线电台（站）的，或者非法使用、占用无线电频率，从事违法活动的。**

**解读：**

| 违法行为 | 处罚 |
|----------|------|
| 故意干扰无线电业务 | 5-10日拘留 |
| 产生有害干扰且拒不消除 | 5-10日拘留 |
| 未经批准设置基站 | 5-10日拘留 |
| 情节严重的 | 10-15日拘留 |

::: warning 这意味着什么？
如果你使用 SDR 设备发射信号，未采取适当的屏蔽措施，并干扰到公共通信网络，可能会被**行政拘留 5-15 天**！
:::

### 《中华人民共和国刑法》

对于情节特别严重的无线电违法行为，可能构成刑事犯罪：

> **第二百八十八条** 违反国家规定，擅自设置、使用无线电台（站），或者擅自使用无线电频率，干扰无线电通讯秩序，情节严重的，处三年以下有期徒刑、拘役或者管制，并处或者单处罚金；情节特别严重的，处三年以上七年以下有期徒刑，并处罚金。

## 如何合法进行实验？

### 方案一：使用射频屏蔽箱（推荐）

射频屏蔽箱可以将无线电信号限制在箱体内部，不会对外部造成干扰。

<figure>
  <img src="/images/5g-architecture/rf-shielded-box.svg" alt="射频屏蔽箱示意图" style="max-width: 400px; margin: 0 auto; display: block;" />
  <figcaption>射频屏蔽箱可以有效防止信号泄漏到外部</figcaption>
</figure>

**优点：**
- 完全合法，无需申请许可
- 不会干扰外部通信
- 可以使用任意频率进行实验

**缺点：**
- 需要购买屏蔽箱（价格从几百到数万元不等）
- 无法进行远距离通信测试

**购买建议：**
- 衰减量至少 60dB 以上
- 确保屏蔽箱尺寸能容纳你的设备
- 注意屏蔽箱的频率范围要覆盖你使用的频段

### 方案二：极低功率 + 线缆直连

将 SDR 发射功率降到最低，并使用同轴电缆直接连接发射端和接收端，加上适当的衰减器。

```
┌────────┐      ┌──────────────┐      ┌────────┐
│  SDR   │──────│ 30dB 衰减器   │──────│  UE    │
│ (gNB)  │      │ (同轴连接)    │      │        │
└────────┘      └──────────────┘      └────────┘
```

**注意：** 即使使用线缆连接，也应确保发射功率极低，防止电磁泄漏。

### 方案三：申请实验无线电台执照

如果需要进行空口测试，可以向当地无线电管理机构申请实验无线电台执照。

**申请流程：**
1. 向省级无线电管理机构提交申请
2. 说明实验目的、使用频率、发射功率、使用地点
3. 等待审批（通常需要数周）
4. 获得执照后在批准范围内使用

**适用场景：**
- 高校/研究机构的科研项目
- 企业的产品研发测试
- 政府部门的技术验证

### 方案四：使用 ISM 频段（有限制）

工业、科学和医学 (ISM) 频段可以免许可使用，但有严格的功率限制：

| 频段 | 频率范围 | 最大功率 | 备注 |
|------|----------|----------|------|
| 2.4 GHz ISM | 2400-2483.5 MHz | 100 mW EIRP | WiFi/蓝牙频段 |
| 5.8 GHz ISM | 5725-5850 MHz | 25 mW EIRP | 注意与 WiFi 区分 |

**注意：** 5G NR 使用的 n78 (3.5 GHz) 和 n41 (2.5 GHz) 频段**不是 ISM 频段**，需要许可才能发射！

## 实验安全检查清单

在开始实验之前，请确认以下事项：

- [ ] **了解法规**：已阅读并理解本页内容
- [ ] **屏蔽措施**：使用射频屏蔽箱或线缆直连方式
- [ ] **功率控制**：发射功率设置为最低可用值
- [ ] **频率选择**：使用的频率不会干扰周围设备
- [ ] **应急准备**：知道如何快速关闭发射设备
- [ ] **环境检查**：实验环境远离机场、医院、政府机关等敏感区域

## 常见问题

### Q: 我只是在家里实验，功率很低，会被发现吗？

**A:** 不要抱有侥幸心理！无线电管理部门有专业的监测设备，可以精确定位非法无线电发射源。即使功率很低，如果对运营商网络造成干扰，运营商会向无线电管理部门投诉。

### Q: 使用 srsRAN 模拟器模式需要遵守这些规定吗？

**A:** 如果使用纯软件模拟（不连接 SDR 硬件），不涉及无线电发射，不需要遵守无线电法规。但一旦连接 SDR 并发射信号，就必须遵守。

### Q: 购买屏蔽箱有什么推荐？

**A:** 可以在淘宝、京东搜索"射频屏蔽箱"或"RF Shield Box"。选择时注意：
- 屏蔽效能（至少 60dB）
- 尺寸（能放下你的设备）
- 有馈通接口（方便连接电源和网线）

### Q: 学校实验室可以直接做实验吗？

**A:** 建议先咨询学校的无线电管理相关部门。许多高校已经申请了实验频率使用许可，在特定实验室内可以合法进行实验。
