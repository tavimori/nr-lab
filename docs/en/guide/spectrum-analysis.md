# Spectrum Analysis

This guide explains how to use SDR devices to observe and analyze nearby radio spectrum, including cellular and WiFi signals.

::: warning
This guide is for **receiving** and **observing** spectrum only — no transmission is involved. Passive reception is legal in most jurisdictions, but please verify your local regulations.
:::
